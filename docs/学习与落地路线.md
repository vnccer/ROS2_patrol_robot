## 2. 给后续 Agent 的协作约定

1. **小步拆解**：每次只聚焦 1 条功能链路或 1 个文件片段，把其中用到的 C++ 语法和 ROS2 机制分开讲清，不一次性倾倒长篇概念。
2. **禁止直接替写完整代码**：涉及新功能或练习题时，优先引导作者先写中文思路/伪代码并自己动手敲，仅在卡点、报错或设计取舍时给提示与代码评审。
3. **强制主动输出检验**：每学完一小块，让作者用自己的话复述（费曼检验）或完成一个小改动/单测，确认真懂后再推进下一步。

## 3. 四阶段推进路线

### 阶段 1：啃透现有代码，做到“能讲清 + 能默写骨架”

> 先不急着加新功能，通过现有短小精悍的源码跨过 C++ / ROS2 入门线。

- [ ] **吃透并默写 [patrol_node.cpp](../src/patrol_manager/src/patrol_node.cpp)（112 行）**
  - 掌握最小 ROS2 C++ 节点骨架：`rclcpp::Node`、Pub/Sub/Timer/Service、Lambda `[this]`、`SharedPtr`。
  - 过关标准：合上源码（可查 API 文档），独立写出一个最小观察节点并编译运行通过。
- [ ] **脱离 ROS2，拆解 [mission.hpp](../src/patrol_manager/include/patrol_manager/mission.hpp) 核心 4 条链**
  - 只追 4 条主线：功能 1（`Effect`/`drain`）、功能 2（循环巡逻）、功能 4（报警入队）、功能 5（高优抢占 + 取消屏障 + `token`）。
  - 逐个吃透高频出现的 8 个 C++ 知识点：`class/struct` 访问权限、引用 `&` 与 `const`、`vector`/`set` 与迭代器、`std::optional`、`unique_ptr`/`SharedPtr`、Lambda、`enum`、`std::move`。
  - 配合 [test_mission.cpp](../src/patrol_manager/test/test_mission.cpp) 用 GDB 单步跟踪 `active`、`flying`、`cancelling`、`token`、`queue` 的变化。
- [ ] **梳理 [mission_node.cpp](../src/patrol_manager/src/mission_node.cpp) 的 ROS2 适配层**
  - 重点看参数加载、Topic/Service、Nav2 Action Client 异步回调，以及 50 ms `tick()` + `drain()` 如何驱动 `mission.hpp`。
- [ ] **白纸复述检验（面试自测）**
  - 合上文档，手画架构图并脱稿讲清 3 个高频问题：
    1. 为什么把 `mission.hpp` 与 `mission_node.cpp` 解耦？
    2. 抢占时为什么需要 `cancelling` 取消屏障和递增 `token`？
    3. 为什么 Nav2 速度不直接发给底盘，中间要加 `velocity_guard`？

### 阶段 2：独立编写新模块，跨过“写不了代码”

> 对应 [开发笔记](./ROS2自主巡检项目_开发笔记.md) 第二阶段（任务 10～15），沉淀完全由自己设计并实现的核心模块。

- [ ] **任务 10**：摸透轻量仿真与 Gazebo 的 TF 树、RViz2 调试与 Costmap，支持动态投放障碍物。
- [ ] **任务 11～12**：独立编写 C++ 感知节点 `anomaly_detector`（`tf2_ros`、`LaserScan`、`OccupancyGrid` QoS、纯 C++ 算法解耦与单测），实现异常自动上报 `/patrol/incidents`。
- [ ] **任务 13～14**：自定义 `InspectTarget.action` 并实现 `rclcpp_action::Server`，将双 Action 状态机与取消屏障接入调度器，补齐黑盒回归验收。
- [ ] **任务 15**：切到 Gazebo + AMCL 跨仿真验证，理解 `use_sim_time` 与定位噪声下的参数调优。

### 阶段 3：真机部署落地

> 复用上层 `patrol_manager` 与 `velocity_guard`，只替换最底层仿真，按 4 步逐层打通：

- [ ] **底盘与雷达独立打通**：验证 `/cmd_vel` 运动方向、`/odom` 与 `odom→base_link` TF、`/scan` 与 `base_link→laser` 外参（URDF）。
- [ ] **真机建图与原生 Nav2 跑通**：用 `slam_toolbox` 建图，调通 `Nav2 + AMCL` 自主导航避障（记录轮速、膨胀半径、AMCL 等调参过程）。
- [ ] **接入本项目上层系统**：新增 `real_robot.launch.py`（关闭 `lightweight_sim` 与静态 `map→odom`），先低速限幅验证多点巡逻、急停锁存、断流停机保护与报警抢占。
- [ ] **留存落地证据**：录制「RViz + 真机实拍」演示视频，记录实测指标（巡逻成功率、抢占耗时、急停刹停时间、到点精度、真机踩坑与解决过程）。
